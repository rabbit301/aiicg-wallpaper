目标
- 修复通知中心删除通知 401（Unauthorized）错误

背景
- 删除 API 走 Go 后端 `/api/v1/notifications/:id`，需 JWT。前端 `api-client` 从 `localStorage.authToken` 注入 Authorization 头。
- 弹窗登录 `AuthModal` 原先走 Next 本地登录，普通用户未下发 `auth_token` Cookie 且未拿到 `access_token`，导致后续请求无 Authorization。

实施方案（已执行）
- `AuthModal` 改为使用 `api.auth.login/register`。成功后调用 `onSuccess(user, access_token)`。
- `Navbar` 调整 `handleAuthSuccess`，调用 `login(user, token)`，由 `AuthContext` 持久化 token。

变更文件
- `src/components/AuthModal.tsx`
- `src/components/Navbar.tsx`

验证要点
- 登录后本地存在 `localStorage.authToken`。
- 调用删除通知接口时请求头包含 `Authorization: Bearer <token>`。
- 后端返回 200，通知从列表移除。

后续建议
- 对所有用户可见字符串完成 i18n 覆盖，移除硬编码中文。
- 为通知 API 增加前端错误提示国际化文案。
