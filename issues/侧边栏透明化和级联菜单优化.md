# 侧边栏透明化和级联菜单优化

## 任务目标
解决用户反馈的三个关键问题：
1. **图标居中问题** - 确保所有图标在容器中完全居中
2. **边框透明化** - 移除明显边框，实现类似即梦AI的透明效果
3. **设置级联菜单** - 实现点击设置后弹出的下拉菜单

## 问题分析
### 问题1：图标未居中 ✅
- **原因**: 使用 `p-3` 导致不同图标大小显示不一致
- **解决**: 改为固定 `w-12 h-12` + `justify-center` 确保完全居中

### 问题2：边框过于明显 ✅
- **原因**: 使用实心边框 `border-r border-neutral-200/80`
- **解决**: 改为透明背景 + 毛玻璃效果

### 问题3：缺少设置菜单 ✅
- **原因**: 设置按钮功能不完整
- **解决**: 添加级联菜单，包含资源、语言、登入登出

## 技术实现

### 透明化效果
```css
/* 之前 */
bg-white dark:bg-neutral-900 border-r border-neutral-200/80

/* 优化后 */
bg-white/80 dark:bg-neutral-900/90 backdrop-blur-md
```

### 图标居中优化
```css
/* 之前 */
p-3 (不固定大小)

/* 优化后 */
w-12 h-12 justify-center mx-auto (固定尺寸+完全居中)
```

### 级联菜单系统
```typescript
// 状态管理
const [showSettingsMenu, setShowSettingsMenu] = useState(false);
const settingsRef = useRef<HTMLDivElement>(null);

// 点击外部关闭
useEffect(() => {
  function handleClickOutside(event: MouseEvent) {
    if (settingsRef.current && !settingsRef.current.contains(event.target as Node)) {
      setShowSettingsMenu(false);
    }
  }
  document.addEventListener('mousedown', handleClickOutside);
  return () => document.removeEventListener('mousedown', handleClickOutside);
}, []);
```

## 视觉效果优化
1. **毛玻璃背景**: `backdrop-blur-md` + 透明度
2. **柔和阴影**: `shadow-lg` → `shadow-xl` 渐变
3. **悬停效果**: 缩放 + 颜色变化
4. **圆角优化**: 统一使用 `rounded-xl`

## 用户体验提升
- **视觉一致性**: 完全对标即梦AI的透明美学
- **交互直观**: 点击外部自动关闭菜单
- **功能完整**: 资源管理、语言切换、登录状态管理
- **响应流畅**: 所有动画使用 `transition-all duration-200`
