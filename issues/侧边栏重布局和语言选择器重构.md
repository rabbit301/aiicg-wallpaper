# 侧边栏重布局和语言选择器重构

## 任务目标
完全对标即梦AI的侧边栏设计：
1. **垂直布局优化** - 图标在上，文字在下，整体垂直居中
2. **移除tooltip系统** - 直接显示文字标签，不需要悬停
3. **自定义语言选择器** - 替换丑陋的LanguageToggle组件
4. **重新定义资源菜单** - 改为法律政策相关内容

## 问题分析

### 问题1：布局不符合即梦AI ✅
- **原因**: 使用水平布局 + tooltip悬停显示
- **解决**: 改为垂直布局，图标上文字下，直接显示

### 问题2：语言选择器设计丑陋 ✅  
- **原因**: 使用原有LanguageToggle组件，占位符和箭头不美观
- **解决**: 自定义级联选择器，支持多语言

### 问题3：资源菜单定义错误 ✅
- **原因**: 误解为文件资源管理
- **解决**: 改为法律政策：服务条款、隐私政策等

## 技术实现

### 布局结构重构
```typescript

  <Icon className="h-5 w-5" />

</Link>

// 优化后：垂直布局 + 直接显示

</Link>
```
