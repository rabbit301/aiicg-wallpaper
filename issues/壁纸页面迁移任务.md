# 壁纸页面迁移任务

## 任务概述
将 `CategoryDetailView` 组件的功能迁移到 `/wallpaper` 页面，解决 "The default export is not a React Component" 错误，并根据用户反馈重新设计页面布局，优化侧边导航栏，修复个人中心硬编码英文问题。

## 问题分析
- `/wallpaper/page.tsx` 文件为空，导致 Next.js 无法找到默认导出的 React 组件
- 需要将现有的分类详情视图功能迁移到壁纸专用页面
- 用户反馈：子分类侧边栏很难看，顶部空白区域不美观
- 用户反馈：顶部计数显示太丑，筛选面板交互需要优化
- 用户反馈：侧边导航栏需要删除文字提示
- 用户反馈：个人中心导航栏中成就和账单有英文硬编码
