目标
- 新增 `src/app/admin/notifications/page.tsx` 管理页，实现发布通知、查看列表（分页/筛选），并通过 Go 后端向全体用户下发。

接口
- POST `/api/v1/admin/notifications` 创建通知（需管理员权限）。
- GET `/api/v1/notifications` 列表，支持 `types[]`、`priorities[]`、`is_read`、`is_starred`、`page`、`page_size`。

前端实现
- 使用 `api.admin.notifications.create(data)` 发布；列表复用 `api.notifications.getList(params)`。
- 文案走 `useLanguage().t('pages.admin.notifications.*')`，遵循 design-system。

测试步骤
1) 超管登录 -> 访问 `/admin/notifications` -> 发布一条系统公告。
2) 普通用户登录 -> 打开通知中心，能看到该通知；执行删除、标记已读、收藏均成功。
