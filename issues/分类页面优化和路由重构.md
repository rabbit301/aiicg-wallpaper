# 分类页面优化和路由重构任务

## 任务概述
优化分类页面的布局和国际化，将路由从 `/category/wallpaper` 改为 `/wallpaper`，提升用户体验和代码结构。

## 问题分析
1. **路由结构**: 当前使用 `/category/[slug]` 路由，不够简洁
2. **硬编码中文**: CategoryDetailView.tsx中有大量硬编码中文
3. **页面布局**: 需要优化布局，适配极简侧边栏设计
4. **翻译键缺失**: 缺少分类页面相关的翻译键

## 解决方案
1. **路由重构**: 创建新的 `/wallpaper` 页面，删除旧的 `/category/[slug]` 路由
2. **国际化完善**: 添加完整的分类页面翻译键，移除所有硬编码中文
3. **布局优化**: 适配16px宽侧边栏设计，优化瀑布流布局
4. **组件重构**: 优化CategoryDetailView组件，改进用户体验
