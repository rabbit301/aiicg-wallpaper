# AIICG壁纸站前后端分离迁移任务

## 任务背景
原项目存在数据混乱、API不明确、用户鉴权和策略混乱、个人中心功能缺失、管理员功能匮乏等问题，需要通过前后端分离重构来解决。

## 技术方案
- **前端**: Next.js 14 + TypeScript (保持现有)
- **后端**: Go + Gin Framework + PostgreSQL + Redis
- **认证**: JWT + RBAC权限体系
- **部署**: Docker + Docker Compose
