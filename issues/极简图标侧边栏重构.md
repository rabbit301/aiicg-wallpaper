# 极简图标侧边栏重构

## 任务目标
参考即梦AI设计，创建极简图标侧边栏：
1. 大幅缩小侧边栏宽度至 w-16 (4rem)
2. 移除文字标签，仅保留图标
3. 添加 tooltip 悬停提示
4. 重新组织导航结构：探索、创造、素材、压缩
5. 底部区域：使用次数、通知、用户中心、设置

## 设计对比
### 之前版本
- 宽度：w-48 (12rem)
- 包含图标+文字标签
- 分类较多，布局拥挤

### 极简版本 ✅
- 宽度：w-16 (4rem) 
- 纯图标设计
- tooltip 悬停显示功能名称
- 清晰的上中下布局结构

## 技术实现

### 布局结构
```
┌─────────────┐
│   Logo      │ 顶部：品牌标识
├─────────────┤
│  探索 🏠    │
│  创造 🪄    │ 中部：主要功能
│  素材 ⊞     │
│  压缩 🖼️    │
├─────────────┤
│  使用次数   │
│  通知 🔔    │ 底部：辅助功能
│  用户 👤    │
│  设置 ⚙️    │
└─────────────┘
```

### CSS 关键技术
- **Flexbox 垂直布局**: `flex flex-col`
- **Tooltip 系统**: 绝对定位 + opacity 过渡
- **图标居中**: `justify-center` + `p-3`
- **响应式适配**: 主内容区 `ml-16`

### 组件优化
1. **SideNav.tsx**: 完全重构为纯图标版
2. **Layout.tsx**: 左边距从 ml-48 → ml-16
3. **CategoryDetailView.tsx**: 内容区侧边栏适配

## 用户体验提升
- **空间效率**: 节省75%的侧边栏空间
- **视觉简洁**: 纯图标设计更现代
- **交互直观**: tooltip 提供清晰指引
- **一致性**: 完全对标即梦AI体验

## 预期效果
- 更宽敞的内容展示区域
- 现代化的极简美学
- 更高效的空间利用
